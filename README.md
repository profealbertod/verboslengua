# Verbos en juego · IES Andrés Benítez

Aplicación web educativa para practicar los verbos de Lengua Castellana mediante retos gamificados.

## Funcionalidades

- Tres modos: conjugación, detective verbal y reto mixto.
- Preguntas de opción múltiple con explicación después de responder.
- Puntos, racha de aciertos y progreso guardados en el navegador.
- Diseño adaptable a móvil, tableta y ordenador.
- Identidad visual cálida basada en la paleta corporativa granate, beige, marfil y dorado.

## Uso

Abre `index.html` en un navegador. No requiere dependencias ni proceso de compilación.

## Publicación con GitHub Pages

En el repositorio, entra en **Settings → Pages** y configura la publicación desde la rama principal y la carpeta raíz (`/`). Cuando GitHub termine el despliegue, la URL pública aparecerá en esa misma sección.

## Nota pedagógica

El banco inicial de preguntas es una base editable para empezar. Puede ampliarse con más verbos, tiempos, modos, personas y niveles de dificultad.
