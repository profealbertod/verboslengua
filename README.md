# Verbos en juego · IES Andrés Benítez

Aplicación web educativa para practicar los verbos de Lengua Castellana mediante retos gamificados.

## Funcionalidades

- Tres experiencias: conjugación, detective verbal y reto contrarreloj de 60 segundos.
- Banco ampliado de preguntas sobre presente, pretéritos, futuro, subjuntivo, modos verbales y formas no personales.
- Entrenamiento por tiempo verbal y filtro de dificultad.
- Sistema de puntos de experiencia (XP) y niveles.
- Medallas por hitos de aprendizaje.
- Repaso inteligente: las preguntas falladas se guardan y pueden practicarse de nuevo; al acertarlas en el repaso, dejan de aparecer en la lista pendiente.
- Progreso, puntos, racha, medallas y errores guardados localmente en el navegador.
- Diseño responsive y accesible, con foco visible y respeto a la preferencia de movimiento reducido.
- Identidad visual del IES Andrés Benítez: granate, beige, marfil y dorado.

## Uso

Abre `index.html` en un navegador. La aplicación no requiere dependencias ni proceso de compilación. Los datos de progreso se guardan en el navegador y no se sincronizan entre dispositivos.

## Publicación con GitHub Pages

En el repositorio, entra en **Settings → Pages** y configura la publicación desde la rama principal (`main`) y la carpeta raíz (`/`). Cuando GitHub termine el despliegue, la URL pública aparecerá en esa misma sección.

## Nota pedagógica

El banco de preguntas es una base inicial ampliada que puede seguir revisándose y creciendo para ajustarse a la programación del aula. Conviene revisar las preguntas y explicaciones antes de usar la aplicación como material de evaluación.
